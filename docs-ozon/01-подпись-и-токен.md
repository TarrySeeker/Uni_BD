# Ozon Acquiring API 1.0.0 — токен и подпись

Рабочая среда: https://payapi.ozon.ru/

## Токен доступа
Создаётся в ЛК эквайринга на каждый магазин (у магазина может быть несколько
токенов, но токен привязан к одному магазину).
При создании задаются:
- URL страницы успешной оплаты
- URL страницы неуспешной оплаты
- флаг «Отправлять POST-нотификации» + URL для них

Статусы токена:
- Активен — боевые операции
- Выключен — операции недоступны
- Тестовый режим — тестовые карты, только оплата картой; реальные карты не проходят, деньги не списываются

## Подпись запроса (requestSign)
accessKey = идентификатор токена из ЛК.
Алгоритм: конкатенация значений полей в заданном для метода порядке,
БЕЗ разделителей и запятых, secretKey — последним. Затем SHA-256, hex.
Это НЕ HMAC — обычный sha256 от строки.

Порядок полей по методам:

| Метод | Порядок |
|---|---|
| POST /v1/createOrder | accessKey expiresAt extId fiscalizationType paymentAlgorithm amount.currencyCode amount.value secretKey |
| POST /v1/confirmOrder | id extId accessKey amount.currencyCode amount.value secretKey |
| POST /v1/updateOrderPositions | id accessKey + пары positions.id и positions.mark, отсортированные по positions.id + secretKey |
| POST /v1/getOrderStatus | id extId accessKey secretKey |
| POST /v1/getOrderDetails | id extId accessKey secretKey |
| POST /v1/createFinalReceipt | id accessKey + пары positions.id и positions.mark, отсортированные по positions.id + secretKey |
| POST /v1/cancelOrder | id accessKey secretKey |
| POST /v1/listPostings | orderId accessKey secretKey |
| POST /v1/cancelPostings | orderId + отсортированные postingNumbers + accessKey secretKey |
| POST /v1/refundOrder | id extId accessKey amount.currencyCode amount.value secretKey |
| POST /v1/createPayment | extId accessKey secretKey |
| POST /v1/getPaymentDetails | id accessKey secretKey |
| POST /v1/cancelPayment | id accessKey secretKey |
| POST /v1/refundPayment | extId paymentId accessKey secretKey |

Примеры значений:
- accessKey: 63fd43a4-f16d-4c3a-9bdf-50f2328781db
- expiresAt: 2025-10-01T20:00:00.000Z (может быть пустым)
- extId: MyOrderID-1
- fiscalizationType: FISCAL_TYPE_SINGLE (может быть пустым)
- paymentAlgorithm: PAY_ALGO_SMS
- amount.currencyCode: 643
- amount.value: 100
- secretKey: PnHtbKc0lLiTlo4WITnWB44Qb1kpygRl

Контрольный пример (ПРОВЕРЕН, сходится):
fingerprint = 63fd43a4-f16d-4c3a-9bdf-50f2328781db2025-10-01T20:00:00.000ZMyOrderID-1FISCAL_TYPE_SINGLEPAY_ALGO_SMS643100PnHtbKc0lLiTlo4WITnWB44Qb1kpygRl
requestSign = 406d29c45ffcb991eb40c3fbce98e714c1ed8963fee0024d7c3ba80dabc407bd

Пустые поля (expiresAt, fiscalizationType) участвуют в строке как пустая строка.
amount.value в примере = 100 при currencyCode 643 — уточнить единицы (рубли или копейки).
